# Topology Lab — графический интерфейс

## Назначение

Topology Lab — локальная исследовательская GUI-среда для топологической
оптимизации, FEM и Scientific ML с переключением **English / Русский**.
GUI использует те же расчётные модули и архитектуры, что и командная
строка: численные расчёты и обучение выполняются реальными Python-процессами.

## Установка и запуск

В корневом каталоге репозитория, рекомендуется Python 3.12:

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# Windows PowerShell: .\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-gui.txt
python -m streamlit run topopt/mlnext/gui.py
```

Интерфейс откроется в браузере. Если вкладка не открылась:
`http://localhost:8501`.

Язык меняется через селектор **Language / Язык** в левой панели.

## Разделы

1. **Обзор:** состояние проекта, активные задачи, число датасетов и моделей.
2. **Датасеты:** количество FEM-задач, разрешение сетки, random seed,
   число итераций OC. В журнале сохраняются ошибки и несошедшиеся задачи.
3. **Обучение:** residual U-Net, GNN, FNO, learned density update;
   эпохи, early stopping, размер батча, seed, дополнительный физический
   compliance loss для U-Net. Сохраняются веса и история обучения.
4. **Сравнение моделей:** однотипный датасет, несколько архитектур и seed,
   проверка каждой с эталонными OC и Ridge, учёт времени и FEM-вызовов.
   Также можно проверить уже обученные checkpoints.
5. **Генеративный дизайн:** обучение conditional diffusion / DiT и
   FEM-проверка сгенерированных плотностей с последующим OC-уточнением.
6. **Нейросетевой FEM:** обучение приближения узловых перемещений и
   сравнение итерационного решателя с нейросетевым начальным состоянием.
7. **Результаты и анализ:** таблицы CSV, JSON-отчёты, графики обучения,
   compliance ratio, время, количество FEM-решений, fallback, визуализация
   полей плотности; скачивание таблиц.
8. **Запуски и журналы:** ход текущей задачи, автоматическое обновление
   информации, журналы расчётов, файлы каждого запуска, отмена процесса.

## Где лежат результаты

Каждый запуск сохраняется в отдельной папке
`artifacts/mlnext/gui/<run-id>/`. В ней находятся:
`run.json` — статус и параметры, `process.log` — журнал,
`best.pt` — обученные веса (если соответствующий этап завершён),
`training.json`, `comparison.csv` и другие расчётные результаты.

Расчётный процесс независим от окна браузера: можно закрыть вкладку
и открыть её снова. Одновременно выполняется одна локальная задача;
внутри «Сравнения моделей» допускается последовательная серия обучений.

## Важные ограничения

Это исследовательское приложение, а не сертифицированный промышленный
FEM-солвер. Показатели ускорения можно считать подтверждёнными только
после независимого тестирования и проверки физических ограничений.

Генерация 900 FEM-задач и длительное обучение на больших сетках
требуют заметных вычислительных ресурсов. Маленькие эксперименты
используются только для проверки корректности workflow, не для
доказательства превосходства нейросетевых архитектур.

Интерфейс рассчитан на **локальное доверенное использование**.
Не следует напрямую открывать его в публичный Интернет без внешней
аутентификации и изоляции окружения.

Пока не реализованы распределённое обучение, автоматическое
возобновление обучения с состоянием оптимизатора, произвольная загрузка
CAD-геометрии и управление удалёнными GPU-серверами.
